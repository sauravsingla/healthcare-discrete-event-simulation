# Security and Data Privacy Policy

## Supported versions

Security and privacy fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability that could expose sensitive data or enable misuse. Contact the repository maintainer privately through the email address associated with the author's public GitHub profile and include:

- affected component and version;
- steps to reproduce;
- expected and observed behaviour;
- potential impact;
- suggested mitigation, when available.

Please allow reasonable time for investigation before public disclosure.

## Data protection scope

This repository is designed for public aggregate datasets and synthetic data. It must not contain:

- identifiable patient information;
- protected health information;
- confidential hospital records;
- credentials, tokens or private endpoints;
- employer-owned or contract-restricted datasets.

Examples and tests should use privacy-safe synthetic inputs. Public datasets must be cited and used in accordance with their licences and terms.

## Clinical safety

The software is a research and decision-support framework, not a medical device or clinical recommendation system. Results require independent validation before operational use.
