## Interpretation boundary

This is an external operational benchmark against official public aggregate NHS data. It supports claims about reproducible data acquisition, temporal holdout forecasting, provider-level scoring, national aggregate error and optional scanner-capacity matching.

It is **not** patient-level validation, clinical validation, causal inference, evidence of improved patient outcomes or proof that the discrete-event simulation is calibrated for a specific hospital.
